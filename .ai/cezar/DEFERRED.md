# Cezar graph workflows: deferred work

The graph workflows (`version: 2`, `*.yaml`) in `.ai/cezar/workflows/` sit beside the older step
workflows (`*.yml`), which are unchanged. The graph set is `issue-to-merge`, `idea-to-spec`,
`spec-to-backlog`, `pr-to-merge`, `maintain-to-intent`, `housekeeping-graph` (the name
`housekeeping` already belongs to `housekeeping.yml`) and `scheduled-scan`.

Items intentionally left out because a prerequisite is missing or a decision is open. Each row
names the trigger that makes it actionable. When a trigger fires, do the item in its own PR and
delete the row.
